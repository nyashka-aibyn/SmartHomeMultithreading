# Ақылды үй жүйесі (Smart Home)

## Жоба туралы

Бұл жоба Java тілінде көп ағынды бағдарламалауды
(Multithreading) қолдану арқылы жасалған.

Жүйеде үш құрылғы бар:

- Шам (Lamp)
- Кондиционер (Air Conditioner)
- Датчик (Sensor)

Әр құрылғы жеке ағын арқылы жұмыс істейді.

## Қолданылған технологиялар

- Java
- Runnable
- Thread
- start()
- run()
- getName()
- sleep()
- join()

## Бағдарламаның жұмысы

1. Үш құрылғы іске қосылады.
2. Әр құрылғы бес түрлі күйді көрсетеді.
3. Құрылғылар жеке ағындарда жұмыс істейді.
4. sleep() арқылы кідіріс жасалады.
5. join() барлық ағынның аяқталуын күтеді.
6. Соңында жалпы аяқталу хабарламасы шығады.

## Мақсаты

Java тіліндегі көп ағынды бағдарламалауды
тәжірибе жүзінде үйрену.
